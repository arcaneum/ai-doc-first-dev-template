## D-001 — Documentation-First Development

**Context**
Starting a new project with AI assistance. Need to ensure long-term clarity and avoid losing rationale for decisions.

**Decision**
Adopt a documentation-first approach where meaningful changes require updating repository documentation.

**Consequences**
- Slower initial execution
- Better long-term understanding
- Easier onboarding for future contributors
- Reduced "why does this exist?" confusion
