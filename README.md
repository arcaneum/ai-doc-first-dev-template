# AI Documentation-First Repo Template

A lightweight framework for AI-assisted software development that prioritises clarity, traceability, and long-term understanding.

## Core Ideas

- Repositories are the source of truth
- AI assists execution, humans retain intent
- Documentation evolves alongside code

This template is tool-agnostic and works with Claude, Gemini, and other LLM-based coding agents.

## Why This Exists

AI tools can write code quickly, but often create "amnesia" — losing the *why* behind decisions. This framework ensures that AI-generated work remains auditable and understandable months later.

## Who This Is For

- Solo developers using AI coding assistants
- Small teams adopting AI-assisted workflows
- Open-source projects that want clear decision trails
- Anyone who wants to use AI without losing context
